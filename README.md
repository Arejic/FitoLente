## Descripción

FitoLente es una aplicación web progresiva (PWA) desarrollada para apoyar en la identificación de plagas y enfermedades en plantas mediante el uso de inteligencia artificial.

El sistema permite capturar o cargar imágenes de plantas para realizar un diagnóstico y consultar el historial de resultados. Actualmente, el diagnóstico está enfocado en **cultivos de coles**.

## Instalación y ejecución del proyecto

### Requisitos

Antes de iniciar el proyecto, es necesario tener instalado:

* Node.js
* npm

Puedes verificar que estén instalados correctamente mediante los siguientes comandos:

```bash
node -v
npm -v
```

### Instalación de dependencias

Clona el repositorio y accede a la carpeta del proyecto:

```bash
git clone https://github.com/Arejic/FitoLente.git
cd FitoLente
```

Después, instala las dependencias del proyecto:

```bash
npm install
```

Este comando instalará las librerías necesarias para ejecutar la aplicación.

### Ejecución en modo desarrollo

Para iniciar el servidor de desarrollo, ejecuta:

```bash
npm run dev
```

Después de ejecutar el comando, aparecerá una dirección similar a:

```text
Local: http://localhost:5173/
```

Abre la dirección indicada en un navegador web para acceder a FitoLente.

## Base de datos y servicios

El proyecto utiliza **Firebase** para los servicios de autenticación y almacenamiento de información.

En caso de que sea necesario instalar Firebase manualmente, utiliza:

```bash
npm install firebase
```

La configuración de Firebase debe realizarse de acuerdo con las credenciales y parámetros establecidos para el proyecto.
